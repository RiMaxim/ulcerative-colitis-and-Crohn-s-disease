**Описание файлов**

1) input_counts.tsv -таблица количества ридов, отнесённых к каждому бактериальному виду (результат EMU)
- Строки: образцы (1, 2, ...). Все образцы в этой таблице имеют количество последовательностей более 5000 в FASTQ-файлах после фильтрации.
- Столбцы: виды бактерий (например, Escherichia coli, Bacteroides fragilis)
- Значения: число прочтённых последовательностей (ридов), отнесённых на референсный геном вида. Из-за особенностей алгоритма EMU значения не являются целочисленными.Таблица количества ридов, отнесённых к каждому бактериальному виду (результат EMU).
2) input.tsv - матрица относительной численности бактериальных видов, полученная с помощью EMU.
- Строки: образцы (1, 2, ...). Все образцы в этой таблице имеют количество последовательностей более 5000 в FASTQ-файлах после фильтрации.
- Столбцы: виды бактерий (например, Escherichia coli, Bacteroides fragilis)
- Значения: относительная численность (доля от 1). Сумма значений в каждой строке равна 1.
3) input_counts_10k.tsv - отфильтрованная версия input_counts.tsv Удалены образцы с количеством последовательностей менее 10 000 в FASTQ-файлах после фильтрации.
4) input_10k.tsv - отфильтрованная версия input.tsv Удалены образцы с количеством последовательностей менее 10 000 в FASTQ-файлах после фильтрации.
5) metadata.tsv - таблица метаданных клинических образцов
- Номер образца, совпадает с ID в таблице input_counts.tsv и input.tsv
- Patient - ID пациента
- visit number - номер визита/временной точки. Целое число
- diagnosis - диагноз пациента. Категория (CD, UC, Control) (см. Термины).
- sex - пол пациента. M / F
- age - возраст пациента. Целое число (лет).
- em - extraintestinal manifestations - внекишечные проявления. 1 (да) / 0 (нет)
- er - Exacerbation - cтатус активности заболевания. 1 (обострение) / 0 (ремиссия)
6) metadata_10k.tsv - таблица метаданных клинических образцов. Содержит те же колонки, что и metadata.tsv, но только для образцов, оставшихся после фильтрации по порогу 10 000 последовательностей в FASTQ-файлах.

**Конвейер по обработке**

1) NanoPlot --fastq $1.fastq.gz -o $1.nanoplot -t 60
2) porechop-runner.py \
    -i $1.fastq.gz \
    -o $1_porechop.fastq.gz \
    --threads 60 \
    --adapter_threshold 90 \
    --end_size 100 \
    --extra_end_trim 5 \
    --verbosity 1
3) gunzip -c $1_porechop.fastq.gz |chopper -q 10 -l 1300 --maxlength 1700 | gzip > $1_porechop_chopper.fastq.gz
4) NanoPlot --fastq $1_porechop_chopper.fastq.gz -o $1.nanoplot_filtering -t 60
5) emu abundance \
    --type map-ont \
    --keep-counts \
    --output-dir ./emu \
    --threads 60 \
    $1_porechop_chopper.fastq

**Термины**

1) Inflammatory Bowel Disease (IBD) - Воспалительные заболевания кишечника (ВЗК). Это собирательный термин, который объединяет два хронических состояния, характеризующихся рецидивирующим (возвращающимся) воспалением желудочно-кишечного тракта. Ключевая особенность — воспаление вызвано аномальным ответом иммунной системы на бактерии кишечника (а не инфекцией). ВЗК включает болезнь Крона и язвенный колит. Важно не путать с СРК (синдромом раздраженного кишечника): при ВЗК есть структурные повреждения тканей и воспаление, а при СРК — только функциональные нарушения.

2) Ulcerative Colitis (UC) - Язвенный колит (ЯК). Хроническое воспалительное заболевание, поражающее только толстую кишку (ободочную и прямую). Воспаление начинается в прямой кишке и непрерывно распространяется вверх по толстой кишке, поражая только слизистую оболочку (самый внутренний слой стенки кишки). Ключевые характеристики: Поражается только толстая кишка (тонкая кишка здорова). Воспаление непрерывное (нет «островков» здоровой ткани). Частые симптомы: кровавая диарея, боль внизу живота, тенезмы (ложные позывы).

3) Crohn’s Disease (CD) - Болезнь Крона (БК). Хроническое воспалительное заболевание, которое может поражать любой отдел ЖКТ — от рта до ануса, но чаще всего терминальный отдел подвздошной кишки (тонкая кишка перед толстой) и толстую кишку. Воспаление затрагивает все слои стенки кишки (трансмуральное). Ключевые характеристики: Может быть в любом месте ЖКТ. Поражение сегментарное («прыгающее») — участки воспаления чередуются со здоровой тканью. Глубокие язвы, свищи (патологические ходы между органами), стриктуры (сужения).
